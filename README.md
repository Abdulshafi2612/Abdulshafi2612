## About Me

I am a **Backend Software Engineer** focused on building reliable, maintainable, and production-ready backend systems using **Java, Spring Boot, PostgreSQL, Redis, RabbitMQ, Docker, and REST APIs**.

I worked at **Siemens EDA** as a Backend Development Intern and Part-Time Backend Engineer, contributing to a large production-scale Java codebase. My work included debugging complex issues, improving performance, writing automated tests, resolving code quality issues, and contributing to maintainable backend systems.

I care about **clear thinking before coding**, **simple practical solutions**, **testing**, **performance**, **system reliability**, and **safe incremental improvements**.
